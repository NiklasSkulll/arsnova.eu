# 1C-Abschlussdokumentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ergebnisbericht, ADRs und Begleitdokumente für 1C, aus denen PR-Beschreibung, Handout und Folien ohne Chats entstehen.

**Architecture:** Neue Dateien in `docs/referat-thema-1/` (Bericht, `adr/`, Eigenanteil, Gerüst) fassen zusammen und verlinken auf die bestehenden Dossiers, Designs, Protokolle und Rohdaten; Bestandsdateien werden nur mit Kennzeichnung aktualisiert. Zwei Claude-Code-Sitzungen (Laptop führt, PC zugeteilte Dateien), Abstimmung per Nachricht.

**Tech Stack:** Markdown, Prettier, ein Linkprüf-Skript im Scratchpad (Node, nicht im Repo).

**Spec:** [`2026-11-05-1c-doku-design.md`](2026-11-05-1c-doku-design.md)

## Global Constraints

- Deutsch; Fachbegriffe, Code und Bezeichner englisch.
- Jede Zahl und jede Behauptung mit Quelle (relativer Link mit Anker, Commit-Hash oder Rohdatei); keine Tabellen aus Protokollen kopieren, sondern zusammenfassen und verlinken.
- Nicht ändern: vorregistrierte Designs (`specs/2026-10-2*-*-design.md`), Protokolle (`evidenz/1C/2026-1*-*.md`), Messdaten (`evidenz/1C/messung/*`), `final-prompt-for-git-diff.md`.
- Kein Produktivcode, keine Issues anlegen, PR #12 bleibt Draft.
- Keine Matrikelnummer, keine E-Mail-Adresse, nichts aus `arsnova-notes` oder `1C-pruefungsfrage-vorbereitung.md`.
- Aktualisierungen in Bestandsdateien sichtbar markiert: `> **Aktualisiert 2026-11-05:** …`.
- Conventional Commits (`docs(referat): …`) ohne KI-Attribution; kein `--no-verify`; vor jedem Push `git pull --ff-only`.
- Gate je Commit: `npx prettier --check <geänderte .md>`, `git diff --check`, Linkprüfung ohne Fehler (Task 1).

## Review Focus

- Zahlen, die vom Protokoll abweichen (gerundet anders, Laptop/PC vertauscht): Stichprobe je ADR gegen den verlinkten Anker.
- Anker, die nach Prettier oder Umbenennung (V1 → U1) nicht mehr auflösen: Linkprüfung über alle `.md` im Ordner.
- Namenskollision V1 (Gegenvariante Teil 2) gegen U1 (Ursachenversuch): `grep -n '\bV1\b'` in neuen Dateien darf nur die Gegenvariante meinen.
- Eigenanteil überzeichnet: keine Formulierung „ich habe … gemessen/entworfen“, wo laut „KI-Nutzung“ die KI entworfen hat.
- Empfehlung als umgesetzt dargestellt: kein ADR mit Status `angenommen` für etwas, das nur empfohlen ist (`--cache-ram`, Byte-Schätzung, T2.3, T3.1).
