## Diskussion: vorbereitete Antworten

| Mögliche Frage                                                 | Kurzantwort                                                                                                                                                                                                                                                                                                                                                                | Beleg                                                                                                                                                          |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Schützt das private Netz die Runtime ausreichend?              | Nein, allein nicht: Firewall erlaubt Port 8080 nur vom App-Host, dazu ein Bearer-Token, der allerdings im Klartext über HTTP läuft. Datenschutz hängt am Inhalt der Prompts, nicht am Netz.                                                                                                                                                                                | [ADR 1B-003](adr/1B-003-laborregel-virtuelles-netz.md), [Belege M1](evidenz/1B/messung/2026-11-13-belege/), [Aufbauprotokoll](evidenz/1B/2026-11-12-aufbau.md) |
| Warum Messung am Draht statt Logging im Code?                  | Kein Produktionscode erlaubt; der Mitschnitt misst dieselbe Grenze, die der Betrieb sehen müsste.                                                                                                                                                                                                                                                                          | [ADR 1B-006](adr/1B-006-zeitmessung-per-mitschnitt.md)                                                                                                         |
| Sind zwei VMs auf einem Laptop aussagekräftig für zwei Server? | Für die Zeitzerlegung ja, für die Rückwirkung auf den App-Host nicht: beide VMs teilen CPU und Cache. Das virtuelle Netz ist schneller als ein echtes; der Abstand zur Schwelle (0,43 ms gegen 50 ms) ist aber groß. Hauptwert in Millisekunden, weil der Prozentanteil auf langsamer Hardware hoch ausfällt.                                                              | [ADR 1B-002](adr/1B-002-topologie-zwei-vms-ein-rechner.md), [1B-Ergebnis](1B-ergebnis.md)                                                                      |
| Wer ist verantwortlich, wenn die Runtime ausfällt?             | Die App fällt auf die extraktive Zusammenfassung zurück; im Labor nach 88,5 ms im Median, ohne Wartezeit (M3 B0, [Laufprotokoll, Nachtrag](evidenz/1B/2026-11-13-lauf.md#nachtrag-2026-11-13-abends-ergänzende-messungen-m1m4)). Betrieb der zweiten Rolle liegt beim Operator (Sofort-Rollback, Regelbetrieb); einen Ablauf für den Tokenwechsel nennt das Runbook nicht. | M3 B0, Second-Host-Runbook §15–16                                                                                                                              |
| Lohnt sich die zweite Rolle?                                   | Schritte 3–4 (Niklas).                                                                                                                                                                                                                                                                                                                                                     | [1B-Ergebnis](1B-ergebnis.md)                                                                                                                                  |
